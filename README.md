# 🧪 다이어터 연금술사 (Dieter Alchemist)

동물의 숲 같은 **코지 라이프 시뮬 + 연금술 크래프팅** 게임.
재료를 채집하고, 연금술로 **물약**과 **크리처**를 제조해서
내 캐릭터의 **비주얼·아우라를 과시**하는 것이 목표입니다.

> 기존 저장소(DragON POKER)와는 분리된 **독립 신규 게임**입니다.
> 순수 HTML/CSS/JS로 서버 없이 동작하며, 진행 상황은 `localStorage`에 저장됩니다.

## ▶ 실행
`dieter-alchemist/index.html`을 브라우저로 열면 바로 플레이됩니다. (별도 빌드/서버 불필요)

## ⚡ 에너지 (행동력)
- 현실 24시간 = 게임 24시간. **로컬 자정(00:00)마다 하루치 1000 충전** (현재 상한 1000)
- **채집(⚡10)**·**연성(⚡25)** 시 소모 (값은 `data.js`의 `ENERGY.cost`에서 조정)
- 상단 에너지 바에 현재량 / 상한 / 다음 충전까지 카운트다운 표시, 앱을 열어둔 채 자정이 지나면 자동 충전
- 추후 크리처·공간 돌보기도 동일한 `spendEnergy()`로 소모 예정. 유료 구매 시 상한 확장 여지(`cap` 분리)

## 🎮 코어 루프 (현재 MVP)
1. **🌿 채집** — 꽃 들판 / 이끼 숲 / 수정 동굴에서 재료를 가중 랜덤으로 획득 (⚡ 소모)
2. **⚗️ 공방** — 가마솥에 재료 2~3개를 넣고 조합 → 새 레시피 발견 (⚡ 소모)
   - 유효 조합 → **물약**(스탯 상승용) 또는 **크리처**(전시용) 제조
   - 무효 조합 → 실패작(재료 소모)
3. **✨ 마이 룸** — 물약을 마셔 비주얼/아우라 영구 상승, 크리처 전시(패시브 매력), **매력 총합 과시**
   - 👗 **내 아바타 + 옷장** — 5개 바디 파츠(머리·몸통·팔·허벅지·종아리)로 조립되는 SVG 아바타 커스터마이징
     - 커스터마이징(잠금/해금): **헤어**(스타일) · **헤어컬러**(기본 5종 + 해금) · **표정** · **문신**(초기 미보유, 플레이로 획득)
     - 옷: 상의·하의 따로 입기 **또는** 원피스(상하 일체)
     - 악세사리: 서클렛 · 귀걸이 · 목걸이 (추후 확장 가능)
     - `starter`가 아닌 항목은 🔒 잠금 → `unlockCosmetic(id)`로 해금 (진행 보상에 연결 예정)

## 📊 등급
매력 총합(비주얼 + 아우라 + 크리처 보너스)에 따라:
🌱 새싹 → 🌸 꽃봉오리 → 🧚 요정 → 👑 뮤즈 → ✨ 여신

## 📁 파일
| 파일 | 역할 |
|------|------|
| `index.html` | 게임 셸 / 3탭 레이아웃 |
| `data.js` | 재료·장소·레시피·등급·옷장 데이터 (`window.GameData`) |
| `avatar.js` | SVG 페이퍼돌 아바타 렌더러 (5 파츠 + 옷/악세사리 레이어, `window.Avatar`) |
| `game.js` | 상태 관리 / 로직 / 렌더링 (`localStorage` 저장) |
| `sfx.js` | WebAudio 기반 효과음 (에셋 불필요) |
| `style.css` | 코지 파스텔 스타일 |
